# Phase II — Unmodified raw JSON sources

These five files are **byte-for-byte copies** from the source repository's `data/provinces/` folder. Do not edit them in this phase.

Original upstream repository:
https://github.com/Derrick-MUGISHA/Rwanda-Province-District-Sector-Cell-Village---in-Rwanda

Attribution: Rwanda administrative hierarchy data, NISR *List of Villages* (2019-07), packaged by rwanda-admin. **Dataset license CC BY 4.0**, see upstream `LICENSE-DATA`. Source date 2019-07-03; copied for this project on 2026-11-16.

- `umujyi-wa-kigali.json`: 1,163 nested villages
- `amajyaruguru.json`: 2,744 nested villages
- `amajyepfo.json`: 3,501 nested villages
- `iburasirazuba.json`: 3,791 nested villages
- `iburengerazuba.json`: 3,617 nested villages

Total: **14,816** nested village objects, plus 2,593 parent units, for **17,409** administrative objects. These are five physical JSON files containing a single nationwide source dataset; the full original country file was **not altered or reconstituted**.

The hashes and all quality findings are in [dataset_card.md](../dataset_card.md). The original source Git object ID of each file is identical to its copied destination object ID.
