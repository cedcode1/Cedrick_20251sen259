## Phase I – Business Process Modeling

### Selected Business Process
**Citizen Search for Available Abanyerondo Contacts**

### Process Description
ABANYERONDO is a system designed to help citizens find security contacts in their area.

When a citizen needs help, they can open the website and select their district and sector. The system checks its records to find Abanyerondo who are currently on duty in that location.

Before contacts can be shown, the system must check that the officers are eligible, assigned to the correct area, and confirmed to be on duty.

If approved contacts are available, the citizen can see them. If no verified contact is found, the system provides information about official emergency assistance.

### Supporting Process
The system also helps manage Abanyerondo duties. It receives personnel information from an external system, automatically prepares duty assignments, and allows authorized supervisors to make changes when necessary.

A supervisor must confirm attendance before an officer is shown as available to citizens.
